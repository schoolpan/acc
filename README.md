# 會計 BLAST 快答遊戲

這是一個模仿 Quizlet 「BLAST 快答遊戲」的單頁應用程式，支援載入會計題庫 Excel 檔並立即開始快速答題練習。整個專案以原生 HTML、CSS、JavaScript 實作，可直接在瀏覽器中使用。

## 功能特色

- 📂 **匯入 Excel 題庫**：支援 `.xlsx`、`.xls`、`.csv` 檔案，會自動解析欄位並提供欄位對應設定。
- 🔁 **雙向練習模式**：可選擇「題目 ➜ 答案」或「答案 ➜ 題目 / 定義」，模擬 Quizlet Blast 的題型切換。
- 🕹️ **60 秒倒數快答**：每題 4 個選項，答對加分、答錯扣分，結束後提供成績摘要。
- 🧊 **太空主題 UI**：重現 Blast 遊戲氛圍，適合課堂展示或個人練習。

## 使用方式

1. 將本專案 clone 或下載 ZIP。
2. 以瀏覽器開啟 `index.html` 即可開始使用，無需額外安裝。
3. 點選「匯入會計題庫 (Excel)」，選擇題庫檔案。建議格式：
   - `題目`：題幹文字（或名詞）。
   - `答案`：正確答案（或詞語）。
   - `定義`：可選欄位，用於「答案 ➜ 題目」模式顯示提示。
4. 確認欄位對應無誤後，選擇練習模式並按「開始遊戲」。

## 題庫格式建議

| 題目 | 答案 | 定義 |
| ---- | ---- | ---- |
| 應收帳款 | Accounts Receivable | 企業對客戶所持有的短期債權 |
| 應付帳款 | Accounts Payable | 公司因購貨尚未付款的短期債務 |

> 若缺少「定義」欄，系統會以題幹內容代替提示。

## 本地開發

若想以本機伺服器方式檢視，可執行：

```bash
python -m http.server 5173
```

接著在瀏覽器開啟 `http://localhost:5173/index.html`。
