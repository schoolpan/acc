# 翻牌遊戲單詞卡

這個專案提供一個可於瀏覽器中執行的翻牌式單詞卡工具，支援匯入 Excel 檔案（第一欄為詞語、第二欄為定義），並具備以下功能：

- 自動播放：依序顯示卡片並於播放過程中自動翻面。
- 隨機模式：隨機打散卡片順序以進行練習。
- 雙向學習：可切換「定義 ➜ 詞語」、「詞語 ➜ 定義」或混合模式。
- 操作方式：點擊卡片即可翻面，使用鍵盤方向鍵或介面箭頭可前後切換。

## 使用方式

1. 於 `web/index.html` 右鍵選擇「使用預設瀏覽器開啟」，或在本地端啟動靜態伺服器後造訪。
2. 點擊「匯入 Excel 檔案」，選擇包含詞語與定義的試算表檔案（支援 `.xlsx`、`.xls`）。
3. 依需求調整顯示方向、播放間隔或啟動自動播放 / 隨機模式。

> 提示：播放時程式會在每張卡片顯示一半時間後自動翻面，可搭配混合模式練習雙向記憶。
